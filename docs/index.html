inert

Is this HTML file safe to open?

Drop in any .html file. inert checks whether it can run code, load trackers or collect passwords, then gives you a copy that looks the same but can't do any of those things.

Drop an HTML file here or click to choose one

Everything runs in your browser. The file is never uploaded, and nothing in it is executed.

    Scripts don't run here, so anything a script would have drawn (like charts) is left out of this copy. To keep charts, use the command-line tool, which renders the page first.

    How it works

    1. Render

    The CLI opens the page in a headless browser and lets its charts draw.

    2. Freeze

    SVG charts stay vector, canvas charts become images, and fonts, styles and images are embedded.

    3. Strip

    Scripts, event handlers, forms, password fields, iframes, trackers and javascript: links are removed.

    4. Lock

    A strict Content Security Policy is added, so browsers block scripts and network access even if something slips through.

    Use it from the command line

    pip install inerthtml
playwright install chromium

inert build report.html          # → report.inert.html
inert verify report.inert.html   # exit code 1 if unsafe
