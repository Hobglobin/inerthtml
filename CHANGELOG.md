# Changelog

## 0.1.0 (first release)

- `inert build`: render with headless Chromium, freeze SVG/canvas charts,
  embed CSS, fonts and images, strip active content, add a strict CSP.
- `inert verify`: check any file against the inert/1 rules, with `--json`.
- Web checker (`docs/`): verify, safely preview and download a "lite" inert
  copy, all in the browser.
- `SPEC.md`: first draft of the inert/1 profile.
- Claude skill in `skills/inert`.
